Plan semanal de aprendizaje en programación para los primeros 3 meses

30–60 min diarios son suficientes. Consistencia > cantidad. Los fines de semana: 1–2 horas de proyecto libre.
Fase 0 — Fundamentos · Semanas 1–4
Semana 1 — Entorno y primeros pasos Python
  • Instala Python, VS Code y Git
  • Aprende variables, tipos de datos y print()
  • Crea tu cuenta en GitHub y sube tu primer archivo
  • Ejercicio: calculadora de suma/resta en terminal
freeCodeCamp · canal MoureDev en YouTube
Semana 2 — Control de flujo Python
  • Condicionales if / elif / else
  • Bucles for y while
  • Listas y diccionarios básicos
  • Ejercicio: adivina el número (juego simple)
Exercism.io (Python track)
Semana 3 — Funciones y Git Python + Git
  • Define y usa funciones con parámetros y return
  • Aprende git add, commit, push, pull
  • Crea un repositorio real en GitHub
  • Ejercicio: lista de tareas en consola
learngitbranching.js.org
Semana 4 — Terminal y SQL básico Linux + SQL
  • Comandos básicos: ls, cd, mkdir, rm, cat
  • SQL: SELECT, WHERE, INSERT, CREATE TABLE
  • Instala SQLite y crea tu primera base de datos
  • Mini proyecto: agenda de contactos con Python + SQLite
sqlbolt.com · overthewire.org (Bandit)
Fase 1 — Desarrollo web · Semanas 5–8
Semana 5 — HTML y CSS Web
  • Estructura HTML: etiquetas, formularios, semántica
  • CSS: selectores, colores, fuentes, modelo de caja
  • Flexbox y Grid para maquetación
  • Proyecto: página personal / currículum en HTML
freeCodeCamp (Responsive Web Design)
Semana 6 — JavaScript básico Web
  • Variables, funciones, eventos en el DOM
  • fetch() para consumir una API pública (ej. clima)
  • Proyecto: página interactiva con JS
javascript.info
Semana 7 — React intro Web
  • Conceptos: componentes, props, estado (useState)
  • Crear app con Vite + React
  • Proyecto: lista de tareas con React
react.dev (docs oficiales)
Semana 8 — Backend con Python (Flask) Web
  • Crea una API REST básica con Flask
  • Conecta tu API a SQLite (CRUD completo)
  • Proyecto fullstack: React + Flask + base de datos
flask.palletsprojects.com
Fase 2 — DevOps · Semanas 9–12
Semana 9 — Docker DevOps
  • Instala Docker Desktop
  • Aprende: imágenes, contenedores, Dockerfile
  • Dockeriza tu app Flask de la semana 8
docs.docker.com · Play with Docker
Semana 10 — Linux avanzado y bash DevOps
  • Permisos, procesos, variables de entorno
  • Scripts bash para automatizar tareas
  • Levanta un servidor con nginx en Linux
linuxcommand.org
Semana 11 — CI/CD y GitHub Actions DevOps
  • Crea un pipeline básico con GitHub Actions
  • Tests automáticos al hacer push
  • Despliega tu app en Render o Railway (gratis)
docs.github.com/actions
Semana 12 — Cloud básico (AWS) DevOps
  • Crea cuenta AWS Free Tier
  • Explora EC2, S3 y IAM básicos
  • Despliega un contenedor Docker en la nube
  • Empieza prep. para certificación AWS Cloud Practitioner
aws.amazon.com/es/training
Semanas 13–18: Ciberseguridad (TryHackMe · redes · CTF) · Semanas 19–24: Datos e IA (pandas · SQL avanzado · scikit-learn · Kaggle)
